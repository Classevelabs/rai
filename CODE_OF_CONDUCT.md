# Code of Conduct

Classeve wants RAI to be a useful technical space for serious engineering work.
Be direct, respectful, and constructive.

Expected behavior:

- Discuss ideas and code on their merits.
- Assume good intent while still being precise about risk.
- Keep disagreements technical and specific.
- Respect maintainer decisions on scope, roadmap, and release quality.

Unacceptable behavior:

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information or secrets.
- Repeated off-topic comments after maintainers ask to stop.
- Abusive issue or pull request activity.

Maintainers may edit, hide, lock, or remove comments and may restrict
participation when needed to keep the project healthy.
